# Консольный индексатор папок на Java

## Описание
Проект сканирует указанную файловую систему, находит дубликаты файлов (на основе SHA-256 хеша) и проверяет изменения между запусками (аналог проверки резервных копий).

Реализован базовый вариант без использования баз данных. Индекс сохраняется в локальный файл `index.csv`.

## Как запустить

### Требования
- Установленная Java (JDK 11 или выше).

### Компиляция и запуск
1. Откройте терминал (командную строку) в папке с проектом.
2. Скомпилируйте файл:
   ```bash
   javac Main.java
